10. 自定义容器（搭配前面 remark-directive，重点！）
 
容器内部可以嵌套上面任意 markdown（标题/列表/代码块）
::: info
# 提示框标题
普通段落
- 列表内容
**加粗文字**
:::

::: warning
警告内容
:::

::: success
成功提示
:::

渲染结果：外层生成  <div class="info"> ，内部 markdown 正常解析。

✅ 在你项目使用的注意事项
 
1. 写完原始markdown后，复制纯文本，使用 JSON Escape 转义，存入json的 content 字段
​
2. 组件必须配置  remarkPlugins={[remarkGfm, remarkDirective, myRemarkContainer]} 
​
3. 换行：Markdown 中单个回车不会换行；两个回车代表段落分隔。
 
单行换行（软换行）：行末尾加两个空格再回车
